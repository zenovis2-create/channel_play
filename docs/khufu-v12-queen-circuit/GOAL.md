# Khufu V12 Queen Circuit Goal

## Intent

Replace the V4 Queen horizontal-passage and chamber blockout with one bounded, readable limestone
destination while preserving every accepted V4–V11 route outside the declared transition.

## Completion Surface

| ID | Class | Requirement |
| --- | --- | --- |
| V12-R-001 | FACT | The route branches horizontally from the V10 Gallery Foot and ends in the conventionally named Queen's Chamber. |
| V12-R-002 | FACT/HYBRID | The chamber reads as limestone, has a gabled ceiling and east-wall niche, and is compressed to the project scale. |
| V12-R-003 | FACT | Two narrow mouth recesses remain non-traversable and receive no purpose claim. |
| V12-R-004 | ENGINEERING | V12 supersedes exactly the audited V4 Queen blockout components without deactivating their GameObjects. |
| V12-R-005 | ENGINEERING | V12 derives V10 successor meshes only from frozen V11-open assets/specs and removes exactly the Queen ownership gate. |
| V12-R-006 | ENGINEERING | The Great Step remains open, threshold posts/lintel remain collidable, and rollback restores every predecessor state. |
| V12-R-007 | GAMEPLAY | A real CharacterController completes the branch round trip and a separate outside-start gate control records an exact named callback hit. |
| V12-R-008 | VISUAL | Six fresh captures prove branch continuity, low-passage rhythm, chamber identity, niche, gable/shaft boundaries, and pyramid integration. |
| V12-R-009 | REGRESSION | Original V4–V11 validation logic passes under exact later-root detachment or restored predecessor bindings. |
| V12-R-010 | PROCESS | Prewrite audit, idempotence, negative controls, clean-index import, external review, exact staging, and post-commit validation are fail-closed. |

## False Completion

V12 is incomplete if it widens the V10 threshold, re-closes the Great Step, changes a V10/V11
source asset, presents a shaft as a route, leaves the V4 Queen blockout visible/collidable, relies
on an overlap-promoted boundary name, exceeds frozen component totals, or reports completion without
fresh built-player and capture evidence.

## Deferred

- Descending passage and Subterranean Chamber.
- ScanPyramids anomalies.
- Global lighting, VFX, production audio, enemies, objectives, and fresh-player usability.
