# Rules

## Scope Boundary

- V5 and V6 builders, validators, materials, and accepted root metrics are frozen.
- New geometry belongs only to `Runtime_Khufu_V7_Entry_Wayfinding`.
- Shared changes are limited to follow-camera configuration, exact pylon cutaway behavior, and its test.
- Guides use the existing V6 scan material and add no colliders, lights, or materials.

## Evidence Rules

- Unity receipts must bind to the current scene SHA256.
- Windows build receipts must bind every changed runtime source and restore PlayerSettings byte-for-byte.
- A rendered screenshot is mandatory; synthetic tests alone cannot approve visual readability.
- Normal and mutation screenshots must be distinct 1536x1024 PNG files.
- Performance is accepted only through direct revalidation of receipt, raw profiler file, screenshots, and log.

## Historical Claim

This is a fictional game map informed by pyramid vocabulary. V7 wayfinding is not archaeological evidence
and must not be described as an authentic reconstruction.
