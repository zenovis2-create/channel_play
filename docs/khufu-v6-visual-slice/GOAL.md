# Goal

## Intent

Make the accepted Khufu V5 pyramid maze visibly closer to a readable limestone pyramid-complex
game space, concentrating production effort on the Temple Hub and dense core without destabilizing
the already verified large-map topology.

## Observable Done Surface

V6 is done only when all of the following are true:

1. The current scene contains the deterministic V6 material and colonnade overlay.
2. V5 topology and gameplay inputs reproduce their frozen SHA256 values.
3. V6 adds no colliders and stays within 12 renderers, 800 vertices, 600 triangles, and 8 materials.
4. Two consecutive rebuilds have the same visual signature and added metrics.
5. Temple Hub and dense-core captures exceed the frozen V5 visual-delta thresholds.
6. V5 static and PlayMode traversal regressions pass against the final scene bytes.
7. A Windows Development Player built from that scene passes the frozen visible-player budget.
8. Mutation-tested aggregate validation passes after an external Fable final-review `ship` verdict.

## False-Done Conditions

A completion claim is false if screenshots point to an older scene hash, performance was measured
without a rendered player window, a V5 frozen input drifted, only compilation was checked, the
generated image was treated as an archaeological blueprint, or Fable did not actually issue the
recorded final verdict.
