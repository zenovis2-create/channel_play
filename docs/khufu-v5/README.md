## Source-of-Truth Order

When documents disagree, use this order:

1. Latest accepted entry in `DECISIONS.md`.
2. Non-negotiable invariants and requirements in `GOAL.md`.
3. Current gate contract in `PLAN.md`.
4. Test definitions in `TEST_PLAN.md`.
5. Live execution state and evidence in `STATUS.md`.
6. Supporting research and prior V4/V2 documents.

`STATUS.md` may report progress but cannot weaken a requirement, test, or gate.

## Evidence Contract

Every completed status line must contain exactly one or more `evidence: KV5-E-NNN` references.
The referenced ledger row must contain:

- requirement and test IDs;
- baseline commit SHA plus artifact fingerprint, or a commit containing the artifact;
- exact command or human-review procedure;
- explicit verdict token;
- non-empty artifact path under `runs/` or successful Fable output under `work/fable-harness/`;
- timestamp.

Accepted completion verdicts are `passed` and `accepted`. `revise`, `investigate`, `blocked`,
`failed`, missing output, or wrapper warnings cannot close a gate.

Before a project commit exists, Gate 0 may use `HEAD:<sha>+ARTIFACT:<sha256>` generated by the
validator. Implementation gates after `KV5-G-000` require a commit containing the tested change.

## Update Protocol

1. Read this snapshot and `STATUS.md` before work.
2. Change only one gate to `[~]` at a time.
3. Add or revise requirements before implementation, never retroactively after a failed test.
4. Run the smallest matching test surface as each item completes.
5. Write the evidence artifact first, then append its ledger row, then mark the item `[x]`.
6. Record any scope or truth-model change in `DECISIONS.md`.
7. Update this snapshot whenever current decision, phase, next action, or blocker changes.
8. Run the harness validator before every Fable review and gate close.

## Validation Command

```powershell
python tools/validate_khufu_v5_harness.py --root .
```

To generate a revision-bound receipt:

```powershell
python tools/validate_khufu_v5_harness.py --root . --receipt runs/khufu-v5-harness/receipt.md
```

Gate 0 can freeze only after the scoped files and final receipt are committed:

```powershell
python tools/validate_khufu_v5_harness.py --root . --receipt runs/khufu-v5-harness-20260710-gate0/final-receipt.md --require-committed
```

The validator checks required files, links, ID uniqueness, requirement-to-test coverage,
completed-status evidence joins, artifact content, and required Fable verdict tokens.
