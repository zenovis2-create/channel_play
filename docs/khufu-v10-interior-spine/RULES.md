# Khufu V10 Interior Spine Rules

## Truth

1. Direct measurements control numeric claims; NotebookLM synthesis never overrides a primary or
   institutional source.
2. The gallery's architectural features may be modeled; their disputed purpose may not be asserted.
3. SP-BV, SP-NFC, and chamber shafts remain non-traversable.
4. Compressed dimensions, widened collision, the north approach, route inlay, and service return are
   tagged HYBRID.
5. The cutaway remains a visualization convention, not a historical opening.
6. V10 runtime names, metadata, receipts, and labels must not contain `Well Shaft`; use
   `Historic_Service_Mouth` and `HYBRID_Service_Return` so the two cannot be conflated.

## Engineering

1. V10 is an independent sibling root and may not modify V4-V9 builder source.
2. The builder is deterministic and idempotent. Generated meshes use stable paths and names.
3. Renderer/collider transitions use an exact audited name allowlist; broad prefix disabling fails.
4. Structural visuals need forward pair checks and an inverse envelope collider inventory.
5. Floor inheritance is explicit and checked by position, scale, angle, and bounds.
6. No new package or runtime dependency is introduced.
7. The exact transition manifest is generated and committed before the first V10 scene write. Its
   target set must have an empty intersection with every V5 Crown route dependency.
8. Gallery enclosure is measured from fixed route samples by bounded hemisphere rays; feature count
   alone cannot pass the embedded-architecture gate.
9. A post-write visual-QA amendment may add renderer-only transitions only when an isolated V10
   comparison proves the integrated obstruction, exact legacy paths and bounds are recorded, collider
   ownership is unchanged, and every count, idempotence, and mutation gate is rerun.
10. The HYBRID return may not contain a rise-then-descent crest at its service landing. The Gallery
    floor must continue beneath the named Great Step wall by at least one controller radius.

## Evidence

1. Unity compile, static validation, PlayMode traversal, Windows player, direct image inspection, and
   profiler evidence are separate gates.
2. Runtime captures delete same-path predecessors and pass freshness, decode, dimension, range,
   standard-deviation, and sampled-color checks.
3. Normal traversal includes fixed anchors and minimum distance. Negative controls must trip a named
   collider and an independently injected error threshold.
4. Controller hit evidence records side, ground, and ambiguous contacts separately. A ground callback
   may not overwrite the side collider used by an exact boundary assertion.
5. Bindings hash the scene, player, assemblies, V10 source/assets, and every runtime build file.
6. The aggregate validator reads the staged index for commit claims and rejects drift or extra files.

## Git

1. Preserve all unrelated modified and untracked files.
2. Stage only the validator-defined V10 allowlist.
3. A scoped commit and passing post-commit validation are required before completion.
