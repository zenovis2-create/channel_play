# Loop: Khufu V10 Interior Spine

## Goal

Produce a deterministic, evidence-bound interior-spine slice without changing accepted legacy
builders or crossing district truth boundaries.

## Trigger

The V9 slice is committed and the next deferred district is `Authentic Interior Spine`.

## State

- baseline commit and scene hash;
- research decision ledger;
- exact V4/V5 transition allowlist;
- generated mesh and scene hashes;
- validator, traversal, image, performance, review, staged, and commit receipts.

## Safety Gates

- audit before scene mutation;
- exact ownership before renderer/collider disable;
- static validation after each build batch;
- circuit break after the same failure twice;
- no completion claim without matching surface evidence;
- no commit until the staged index itself passes.

## Observe-Decide Rules

1. If research and current geometry disagree, preserve the accepted V4 marker contract and mark the
   production geometry HYBRID.
2. If collision data and images disagree, the image/traversal contradiction reopens the gate.
3. If the service route reads as factual reconstruction, change hierarchy/material/receipt language
   before adding more detail.
4. If a legacy validator fails, isolate the V10 batch that changed its surface before proceeding.

## Verification

- deterministic Python checks for aggregate, staged scope, PNG semantics, and bindings;
- Unity audit/static/idempotence/mutation/legacy gates;
- collision-constrained PlayMode and Windows traversal;
- direct inspection of every required view;
- pinned Windows profiler procedure;
- external and local review receipts.
