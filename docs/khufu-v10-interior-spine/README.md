# Khufu V10 Interior Spine

V10 is the next bounded production-art slice after the V9 causeway. It replaces the sparse visual
presentation of the accepted V4 entrance-to-Grand-Gallery spine with deterministic combined meshes,
owned collision, readable factual/adapted boundaries, and Windows traversal evidence.

The slice deliberately stops at the Queen branch threshold, Great Step, and upper service-shaft
mouth. Royal rooms, subterranean rooms, and scan anomalies retain separate ownership.

Start with:

- `GOAL.md` for completion and false-done conditions;
- `RESEARCH_BRIEF.md` for accepted archaeological claims;
- `PLAN.md` and `RULES.md` for implementation boundaries;
- `TEST_PLAN.md` for required proof;
- `STATUS.md` for the live decision.
