   meshes without saving the scene.

- V10 starts at the adapted north-face approach and owns the V4 Entrance -> Branch -> Gallery Foot
  -> Grand Gallery -> Great Step presentation.
- V10 may show only the threshold of the Queen horizontal branch and the upper service-shaft mouth.
- The V10 FACT path uses the accepted compressed V4 marker geometry. Gameplay clearance is HYBRID.
- The return path is an explicit HYBRID service route and must not be described as a measured Well
  Shaft reconstruction.
- Royal Circuit owns the Queen's Chamber, antechamber, King's Chamber, and relieving system.
- Subterranean Threshold owns the below-grade descending passage and Subterranean Chamber.

## Rollback Boundary

Delete only the V10 root, V10 generated assets, V10 scripts, V10 docs, V10 run evidence, and exact
V10 renderer/collider state transitions. Do not edit V4-V9 builders or unrelated dirty files.

## Stop Conditions

- After the same failure twice, stop retrying and switch to blocker analysis.
- Reject numeric success when direct image or traversal inspection contradicts it.
- Do not widen the slice into Royal, Subterranean, scan-void, global-lighting, VFX, or audio work.
