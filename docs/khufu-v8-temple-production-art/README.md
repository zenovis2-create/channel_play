# Khufu V8 Temple Production Art

This package defines the bounded production-art pass for the existing Khufu V5-V7 map. V8 reuses the
audited `pyramid_temple_full_environment.fbx` as an art donor for the Temple Hub while preserving the
accepted route, collision, camera, gameplay, and package state.

The V5 mega-labyrinth remains a fictional game layout. Archaeological facts inform the Temple Hub's
material and spatial vocabulary; V8 is not presented as a complete reconstruction of Khufu's complex.
