## 1. Blocking findings (priority order)

**B1 — The renderer-budget check is arithmetically impossible.** `CollectMetrics` counts *inactive* components: `GetComponentsInChildren<Renderer>(true)` / `<Collider>(true)` (`ChannelPlayKhufuV6VisualFidelityBuilder.cs:154-155`). Disabling a renderer or setting `collider.enabled = false` leaves the component in place, so **suppressing the V4 Queen blockout frees exactly zero budget**. The map is at 829 against `map.renderers_max: 829` (`docs/khufu-v11-royal-circuit/performance-budget.json:10`), so success check 6 ("≤829") cannot hold once V12 adds even one renderer. Fix: V12's own budget declares `829 + N` with `N` (≤5) fixed in the prewrite contract, asserted as an **exact total**, not `≤`. Colliders: 567/600 leaves exactly **33 slots**, and V11 alone consumed exactly 33 (`v11-final-boundary-control.md:19`) — a passage + gabled chamber + niche + two shaft recesses + structural pairs must be proxy-budgeted to ≤33 up front, or the cap raised explicitly with justification.

**B2 — "V11 signature is immutable" is false by construction.** The V11 signature folds the V10 bindings into itself: `lines.Add("v10-binding|" + path + "|" + AssetDatabase.GetAssetPath(mesh))` (`ChannelPlayKhufuV11RoyalCircuitValidator.cs:603-612`), and `ValidateScene` hard-fails with `"V10 open mesh binding mismatch: …"` (same file, `310-313`, `334`). Rebinding to V12-owned assets necessarily changes it. Fix: `RULES` redefines the boundary as "the V11 signature is reproducible only under the restored-V11-binding context," and the evidence records **both** the restored-context value (must equal V11's committed value) and the new as-committed value.

**B3 — The legacy runner does not cover V11, and the V10 delta set will grow.** `ChannelPlayKhufuV11LegacyRegression.cs` runs **five** gates (`gates=5`, line 60); there is no V11 harness to inherit. V10's tolerated set is an exact 13-entry list (`ClassifyV10Transition:114-134`) that will gain at least `V10 mesh omits spec corners: Queen_Ownership_Gate` and `V10 proxy collider drifted: Queen_Branch_Threshold_Queen_Ownership_Gate` (predicted from `"V10_PROXY_" + spec.SegmentId + "_" + spec.Name`, `ChannelPlayKhufuV10InteriorBuilder.cs:98`) — observe, don't assume. Also: removing the gate box drops map-wide vertices/triangles (~24 verts / 12 tris) **even with the V12 root detached**, shifting the V8/V9/V10 metric tokens. Fix: add a V11 gate that **restores bindings in memory** (deterministic pass) rather than classifying V11 failures, keep the existing `finally`-restore + scene-byte equality (lines 53-55, 100-108), and pre-declare every delta as an exact named set with a count.

**B4 — Double ownership: the Queen route glow is already V10's.** `V4_Glow_Queens` and the `V4_Route_Queens_Chamber` renderer are in V10's `SupersededRouteVisuals` (`ChannelPlayKhufuV10InteriorAudit.cs:22-37`) and committed in `disable-manifest.json` with `"DisableRenderer": true` (near lines 1012, 1152). V12 owning them means a V12 rollback re-enables state V10's manifest says is disabled. Fix: exclude both from V12's owned set; **assert** they are already disabled, and express marker preservation as "transform at the manifest-recorded position, renderer stays disabled."

**B5 — The named-callback boundary control is unproven, not "tuning."** V11's own final receipt says `Named boundary contact proof: actual-controller capsule overlap before Move`, `1/15` anchors, `0.635 / 15.514 m` traversed (`v11-final-boundary-control.md:9-14`) — exactly the overlap-based promotion V12 declares unacceptable. Demanding a stricter proof with no probe change is an open-ended late-run loop risk. Pre-commit in `TEST_PLAN`: start ≥1.5 m outside the gate plane on the GalleryFoot→Queen axis at floor level, step ≤0.1 m/frame, assert the pre-`Move` overlap set is **empty**, require the named `OnControllerColliderHit` on the **same frame** `Sides` is reported, and define one explicit deterministic fallback so the gate can close. Also fix the control's ambiguous state: re-enabling the gate must rebind granite to `KhufuV11_V10_Red_Granite_Open` (which still contains the gate box) **and** re-enable `V10_PROXY_Queen_Branch_Threshold_Queen_Ownership_Gate` — proxy-only tests an invisible wall. Mirror `ApplyV10ClosedBindingsInMemory` (`…Builder.cs:287-297`).

**B6 — Missing input precondition and missing derived-mesh invariant.** V11's builder accepts closed-or-open input (`ValidateMeshInput:266-274`); V12's analog must accept **only** {V11 open, V12 open} and fail closed on the frozen closed V10 asset, or a stale scene silently re-closes the Great Step. Add the strongest available invariant, which the plan omits: `V12 granite ≡ V11 granite minus the Queen gate box` and `V12 limestone ≡ V11 limestone` (identical signature), asserted both directions so the filter can't silently drop anything else. Freeze V11's two open assets + `.meta` by SHA256 exactly as V11 froze V10's (`…MeshPipeline.cs:431-472`).

## 2. Secondary constraints to fold into the freeze

- **The opened threshold is already player-legal — do not widen V10.** Posts at ±1.5 m × 0.42 m wide give ~2.58 m clear; lintel underside ~2.46 m above GalleryFoot `y=5.4` (`ChannelPlayKhufuV10InteriorMeshPipeline.cs:268-276`) vs a 0.9 × 2.0 m controller. Assert posts/lintel proxies stay **enabled**.
- **Don't inherit V4's open side.** V4's chamber has floor, back (`z+2.2`), east, west, two gable halves — no `−z` wall — and V4's passage endpoint lands *inside* the room (`V4Builder.cs:353, 381-386`). "Chamber enclosure" must be a real six-sided test with an explicit doorway exception.
- **`V4_Light_Queens` sits inside the new chamber** (`:543`) and lights every capture. Not a renderer, so not in the transition set — declare it preserved-and-relied-upon; note any floor-plane change in the capture manifest.
- **Disable components; never `SetActive(false)`.** V4's `ValidateScene` finds `V4_Queens_Floor` by name and measures its local Y against the 41/280 ratio (`:612-627`). Add a negative control rejecting `SetActive(false)`.
- **Name collision:** V5's forbidden tokens include `"Queens_Shaft"` (`ChannelPlayKhufuMegaLabyrinthV5Builder.cs:417`) — shaft-mouth objects must avoid that token.
- **Document the operational hazard:** after V12, re-running V11's builder silently re-closes the Queen gate, and V11's rollback restores V10-closed. `RULES` should say V11's builder is no longer re-runnable without a following V12 rebuild.

## 4. Decision

Safe as to asset immutability and rollback shape — yes. Sufficient as written — no: B1 (renderer cap), B2 (V11-signature immutability), B3 (legacy scope/count) are contradictory; B4 is a double-ownership conflict; B5 has never been achieved here. **Fix B1–B6 inside the prewrite contract before the first scene write**; land section 2 in the same freeze. Recommendation: **adopt with changes**.
