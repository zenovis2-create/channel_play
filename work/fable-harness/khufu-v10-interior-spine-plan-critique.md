# Fable Plan Critique: Khufu V10 Interior Spine

## Goal

Create a production-art and collision-fidelity overlay for Khufu's accepted V4 north entrance,
ascending passage, and Grand Gallery, without rewriting V4/V5 or crossing Royal/Subterranean truth
boundaries.

## Completion Surface

One bound revision must pass deterministic rebuild, exact visual/collider ownership, historical
feature counts, `1.8m x 2.2m` clearance, collision-constrained PlayMode and Windows traversal,
independent negative controls, semantic screenshots, legacy regressions, pinned D3D11 performance,
staged-index validation, and post-commit validation.

## False-Done Conditions

- visually improved but not traversable;
- seven corbels pass numerically but gallery still reads as a wide freestanding staircase;
- orphaned invisible colliders remain;
- HYBRID service return is presented as measured Well Shaft geometry;
- V10 absorbs Queen, King, relieving, subterranean, or scan-anomaly ownership;
- evidence is stale, unbound, or validates worktree bytes different from the index.

## Repo Facts

- Baseline commit: `a7ba20fd24034a0c5cf115d21d8d955797abe011`.
- V4 root is an accepted compressed 56m-base cutaway with route markers for Entrance, Branch,
  Gallery Foot, Queen, Grand Gallery Top, and King.

- SP-BV/SP-NFC form and purpose remain unknown and are non-traversable.

## Proposed Codex Plan

1. Add an independent sibling root and deterministic combined-mesh kit.
2. Preserve V4 marker transforms; disable only an audited exact list of superseded V4/V5
   renderers/colliders.
3. Own Entrance -> Branch -> Gallery Foot -> Grand Gallery -> Great Step as FACT/HYBRID art.
4. Show Queen branch and service-shaft mouth only as boundaries.
5. Add a visually distinct two-way HYBRID return between Gallery Foot and Branch; do not call it an
   exact Well Shaft reconstruction.
6. Validate forward visual/proxy pairs plus inverse collider ownership.
7. Use normal traversal plus a named blocker mutation and independent 0.75m error control.
8. Re-run V4/V5/V8/V9, Windows, screenshot, performance, staged, and post-commit gates.
